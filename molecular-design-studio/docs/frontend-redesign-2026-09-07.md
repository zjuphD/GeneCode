# GeneCode 前端重设计与验收

日期：2026-09-07。范围：真实 React 工作台，不是静态展示页；本地实现，未发布。

## 审查结论与设计决定

本轮先捕获当前应用截图，再检查真实任务、设置与窄窗口。保持现有品牌、序列引擎、规范文档模型、补丁确认与撤销机制。

| 原界面问题 | 本轮处理 |
| --- | --- |
| 文件标签、应用头部、文档命令与编辑器工具四层横跨页面，文件名重复 | 全局只保留一条顶栏；文件标签及命令移入序列工作区 |
| Agent 像附属侧栏，欢迎、任务、输入区层次割裂 | 左侧对话、右侧序列；对话先于执行流程，输入区独立于滚动区域 |
| 欢迎文案硬编码个人称呼，开始操作不明确 | 面向所有用户的任务引导，保留五类真实任务入口 |
| 输入操作采用绝对定位，容易与快捷键提示挤在一起 | 输入框内部独立操作行，快捷键提示置于其下；保留离线草稿与停止按钮 |
| 窄窗口模拟工具仅剩空白按钮 | 保留文字；编辑器不足 900 px 时让工具回到正常布局、必要时换行 |
| 视图状态栏密集，手机尺寸隐藏特征及历史入口 | 独立底栏，图谱、序列、双视图和面板入口保持可见 |
| 设置占满高度，跨分类信息不易聚焦 | 使用带焦点管理的 MUI Dialog；桌面侧导航，手机横向分类导航 |
| 参数填好后按钮显示状态“已填”，没有表达下一步 | 改为“提交参数（N 项）” |
| 小屏补丁表格挤压长文本，重要动作点击区域过小 | 可键盘聚焦的横向表格区域；加大确认、应用等按钮及警告复选框 |
| 深色状态文字与浅色科学画布混用颜色 | 区分外壳与画布，修复图谱标签和状态文字对比度 |

应用外壳的布局、间距、绿色强调色、响应式规则集中在 `src/ui/workbench.css`，不继续在旧 `App.css` 尾部堆叠整段改版。旧文件保留 OVE 与专业组件兼容样式；本轮没有重写或移除所有历史 CSS。

## 保留的边界

- 未推送 GitHub、部署 Cloudflare、重新打包或签名桌面安装包。
- 本轮没有验证大模型成功规划路径，未变更模型、密钥或外部服务设置。
- 规则回复仍偶尔把结构化输入中的 `INPUTS` / `CONSTRAINTS` 当成目标名称；这是任务解析问题，不应通过隐藏回复掩盖，本轮未改其解析逻辑。
- 后端仅把“左侧图谱”改为位置无关的“序列工作区的图谱”，旧运行记录保留原始文本；已启动进程需正常重启后加载该文案修改。本轮未重启用户服务。
- 已保护旧序列画布的语义配色和编辑行为；未对全部专业弹窗、原生 macOS/Windows/Linux 窗口及触屏设备做穷举验收。
