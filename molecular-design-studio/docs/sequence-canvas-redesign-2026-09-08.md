# 序列画布外观改造 · 2026-09-08

## 设计范围

根据用户提供的 SnapGene 序列截图，采用紧凑的科学轨道布局：双链序列为主、特征位于双链下方、酶名以细线连接切点、引物使用紫色轮廓。保留现有 Agent 外壳与编辑入口，不复制截图中的序列或注释内容。

本轮修改本地实现，不提交 Git、不推送、不部署，不改变用户的碱基、特征或引物数据。

## 已修改

- 特征轨道缩为 18 px，采用细边框、低饱和填色、居中文字；长名称安全省略，完整名称及坐标保留在悬停信息和无障碍名称中。
- 跨行特征只在真实终点绘制箭头，避免每行都出现一个假终点；引物轮廓同样遵循真实方向端点。
- 酶标签按实际文字宽度分层，左右边缘向内排布，连接线仍指向原始切点边界；取消常驻标签框。
- 同组酶使用“名称 · N 酶”说明数量，双击保留完整列表；按正、反链两个切点分组，不能仅凭正链坐标合并。
- 使用宿主已有常用酶名单优先显示 PstI、BamHI 等熟悉名称，不另外维护一份酶目录，也不更改酶匹配结果。
- 密集标签可按行展开、收起，支持鼠标和键盘；展开不更改选区或数据。
- 悬停或键盘聚焦酶名时突出识别区域与双链切点，平末端的同坐标双链标记不再互相去重。
- 修正同切点列表错误声称“所有酶识别序列相同”的文案；同切点不等于识别序列相同。
- 选区操作行保留稳定高度：未选中时显示操作提示，选中后显示操作按钮，避免首次单击引起画布位移、第二次点击错中其他特征。
- 文档标签隐藏重复的长度/拓扑元信息，给真实文档名称留空间；长度和拓扑仍保留在其他信息区。

## 边界与后续

这是截图风格方向的第一版，不是 SnapGene 完整功能复刻。没有新增阅读框彩带、引物错配/5′ 尾部序列可视化，也没有重写酶切计算。引物轮廓本轮未在真实含引物文档上重新完成创建、保存、导出全流程验收。

已有 Vite 大包和混合动态/静态导入警告、range-utils 的 Node ESM 弃用提示仍存在，不阻断本次构建和测试。极端小屏、跨行 Type IIS 识别区域与所有双击/滚动组合不在本次全面验收范围，不能据此宣称全部编辑器功能等同 SnapGene。
