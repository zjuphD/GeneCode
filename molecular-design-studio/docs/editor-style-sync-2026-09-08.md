# 编辑器与 Agent 风格同步

## 目标与审视结论

以当前 Agent 为视觉参照，只调整编辑器与共享工作台的界面表现。实际页面检查发现：文档命令混用实心图标，翻译下拉框有原生表单感，画布工具独占一行且依赖负偏移定位，侧栏和底部切换的边框、强调色不一致。

沿用已有重设计规范：灰白/炭灰中性色、细线图标、轻量交互状态；保留图谱特征配色、碱基等宽字体、坐标语义及 canonical 编辑链路。

## 实现

- 共用 `ui/workbench.css` 的颜色、间距、字体和圆角，不增加新的覆盖样式文件。
- 文档标签、打开/导入/保存、侧栏和视图切换改用与 Agent 一致的 Lucide 细线图标。
- OVE 工具栏通过可选 `portalTarget` 挂入真实工具行；保留 Redux 上下文及原有工具行为，无目标时仍使用原位置。移除对负偏移的依赖。
- 查找控件新增可访问名称，Escape 只关闭查找；限制酶菜单 Escape 返回触发按钮焦点，不传递到工作台。
- 翻译选项使用中文标签，内部值不变。菜单、选择操作、注释/引物表单和侧栏字段同步样式。
- 窄编辑器使用图标命令栏，底部的图谱、序列、双视图、特征和历史保留文字并正常排布。
- 深色模式的工具条和面板与 Agent 一致；科学图谱画布仍保留白底，未反转特征颜色。

## 验证

- Vitest：66 个测试文件，1,040 项通过。结果：`output/editor-style-tests.json`。
- 增加限制酶菜单选择、管理入口与 Escape 焦点回归测试，并检查引擎工具栏目标在编辑器工具行内。
- 生产构建（lint、TypeScript、Vite）通过；仍有原有 OVE 大包及静态/动态混用 import 警告。
- 实际浏览器验证：图谱/序列/双视图切换，查找 GAATTC 并跳转 1/2 → 2/2，编辑锁开关恢复可编辑状态，图层菜单、酶分组菜单、翻译视图切换、注释弹窗打开/取消。
- 默认 1729×1205、390×844、1100×800 检查；无页面横向溢出，底部五个入口在屏幕内。测试结束恢复默认窗口尺寸和跟随系统主题。
- 冷加载后无新增 console error；原有隐藏语义标题保持 1×1；工具行中仅一个 OVE 工具栏，画布内没有重复工具栏。
