# 编辑器优先工作台：第一轮落地与验证

日期：2026-09-08。范围：编辑器布局、选区检查入口、克隆对话框及 Gibson 自定义同源臂保护。保留原有未提交改动；本轮未提交、推送或部署。

## 已落地

- 新工作区默认先展示编辑器；已有用户的 Agent 开关偏好继续保留。
- 布局顺序调整为文库/检查器 → 编辑器画布 → Agent，Agent 不再隔开检查器和画布。
- 文档标签与文件操作在空间足够时共用一行；空间不足时换行。图谱、序列、双视图与侧栏入口保持在底部。
- Agent 右侧停靠，拖动左边界或使用方向键调整宽度；并排模式限制过宽面板，专注对话仍可占满工作区。
- 选区工具条增加“检查选区”。检查器/历史视图默认收起文件列表，保留“文件”按钮按需展开。
- 克隆窗口按输入/校验分栏；桌面两栏独立滚动，窄屏纵向滚动，头部和底部操作不随内容消失。
- 修复嵌套 label 和过大的单选控件；未填序列时显示引导，不预先列出一串错误。
- 坐标必须是 1 到 N+1 的整数，不再把非法输入悄悄归到第一个碱基。
- 自定义 Gibson 左/右同源臂必须分别匹配对应末端，匹配到相反一侧也不能创建；不确定碱基、无有效碱基、越界坐标同样阻止创建。
- 环状 Gibson 构建体的右连接处预览包含跨原点的载体序列。
- 弹窗打开时移入焦点、限制 Tab 范围；Escape 只关闭克隆窗口，不同时关闭 Agent；关闭后焦点返回触发按钮。

## 验证结果

- `npm run test:ci`：66 个测试文件、1,063 项测试全部通过。
- `npm run build`：ESLint、TypeScript、Vite 生产构建通过。
- `git diff --check`：通过。
- 构建仍有既有的大分包与静态/动态混合导入警告，不能视为包体优化已完成。
- 真实浏览器：图谱/序列/双视图切换、选区 → 检查器、Agent 开关/专注模式/方向键缩放、克隆不匹配阻止及清空后恢复、越界阻止、Golden Gate 无真实切点对时禁止创建、Escape 焦点恢复均检查通过。
- 1280 × 720：仅编辑器和 Agent 并排时，编辑器宽约 711 px；三栏同时打开时约 574 px。没有页面横向溢出，底部视图栏完整处于窗口内。
- 390 × 844：克隆输入区与预览区顺序排列，无互相覆盖；底部操作保持在屏幕内。验证后已恢复原始窗口尺寸。
- 本次最终页面检查未捕获到浏览器 console error。

## 验证边界与下一阶段

这不是 SnapGene 功能对等声明。当前计算仍是构建体序列的模拟，不是实验成功保证。本轮没有重新验证真实模型工具调用、湿实验效果或导出后的外部软件往返。

Gibson 默认同源臂长度/GC 属于启发式建议；线性序列端点自动臂的既有回退逻辑未在本轮重写，不能把该预览当作已验证的可订购引物。对应末端的保护规则参考 [NEB Gibson Assembly 原理与引物设计说明](https://www.neb.com/en/tools-and-resources/video-library/primer-design-and-fragment-assembly-using-gibson-assembly)，本地实现采用精确匹配，不模拟错配容忍度。

下一阶段重点：图谱长标签与中心名称布局、线性端点/多片段组装模型、引物与酶切完整操作链、文件往返与大序列性能。现有 OVE 画布标签拥挤和中英文混用仍存在。
