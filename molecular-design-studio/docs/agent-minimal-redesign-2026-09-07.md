# Agent 对话界面重设计与验证

2026-09-07。本地实现，未提交、推送或部署。保留本轮开始前的所有工作区改动。

## 从实际页面发现的问题

实际结果页把任务目标、聊天、工具日志、候选指标、归档说明、文件类型和下载按钮铺成连续的小表单。正文偏小、图标风格不一、重复标题多；原来的放大按钮只是加宽侧栏。空白页也有重复介绍和五块大任务卡，输入区与任务入口分离。

## 本次调整

- 专注对话占据主画布，正文限制为 720 px 阅读宽度；可以切回序列并排，选择保存在本机。工具定位会主动展示序列画布，后台进度不会强制切换视图。
- 空白状态采用标题、集成输入区、轻量任务入口。删除装饰头像和各类实验器材图标；Agent 操作采用同一套细线图标。
- 序列上下文、附件入口、权限选择与发送合并到输入区。聊天独立滚动，输入区不随长结果移出窗口。
- 对话在结果生成后仍可阅读；执行计划、假设、工具记录、文件和设计依据按需展开。结论、风险、构建体复核状态与补丁确认仍保留。
- 候选序列使用等宽字体，参数不再逐个套徽章；文件列表使用明确文件名，主操作和辅助操作分层。
- 修复中文输入法组词时 Enter 误发风险，以及权限菜单 Esc 同时关闭整个 Agent 的行为。权限提示与真实模式一致，自动模式不再声称修改前需要确认。
- 补齐序列文库搜索框样式，避免同屏出现未设计的原生文本框。

## 验证证据

- `npm run build`：通过 ESLint、TypeScript、生产构建。保留既有 OVE 大 chunk 和混合导入警告。
- Vitest：65 个文件、1,037 个测试全部通过；新增输入法、菜单 Esc、上下文跳转、结果后对话可见、模式说明、失败记录展开等回归覆盖。既有补丁确认、附件、撤销、序列写回测试保留。
- 真实浏览器：默认 1699×1205 与 390×844 检查。窄屏页面无横向溢出，结果独立滚动，输入区留在视口内；权限菜单未越界。深色模式和刷新后的专注视图恢复检查通过。
- 真实本地 sgRNA 流程 `run_9c209c01e13c` 已完成规则规划/执行并生成候选；候选切换、复制反馈、结果文件展开可用。未修改原始 pUC19 文档。
- 克隆参数表单可输入、提交并进入下一步计划。但发现下述既有数据解析异常，未执行或应用该克隆方案。
- 最终冷刷新后无新增浏览器 error 日志。

## 未完成的非视觉验证与已知问题

1. 规则解析仍可能把提示中的 `CONSTRAINTS` / `INPUTS` 识别为目标名；本轮没有修改后端规划逻辑。
2. 300 bp 测试序列带 `>demo_insert` FASTA 标题从参数表单提交后，用户摘要显示 310 bp，规划回复显示 306 nt。标题/协议文本污染序列的准确位置尚未重新诊断。不能将该克隆路径宣称为完整验证通过。
3. 本轮真实结果走规则路径，不代表外部 LLM 连接、远程特异性/脱靶检查成功，也不构成实验有效性验证。
4. 点击 CSV 文件下载后，内置浏览器的自动化下载事件等待超时，未确认文件落盘；不能把该操作列为端到端下载通过。CSV 生成与导出相关单元测试通过。
